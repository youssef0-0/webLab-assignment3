# Web Assignment

This project contains two simple pages built with HTML, CSS, and JavaScript.

## Pages

- `validation.html`: Registration form with JavaScript validation for name, email, password, confirm password, and age.
- `data.html`: People table with live search and sorting by name or age.

## How to run

1. Download or clone this repository.
2. Open `validation.html` in a web browser.
3. Use the navigation links to switch between the two pages.

The registration form is a front-end demo. It validates the fields but does not send information to a server.
